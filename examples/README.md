# Trade-A-Plane Scraper API – code examples

Examples for every Trade-A-Plane endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/listing.sh`](curl/listing.sh) | `bash listing.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/listing.php`](php/listing.php) | `php listing.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Listing.cs`](csharp/Listing.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/listing.go`](go/listing.go) | `go run listing.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/ListingExample.java`](java/ListingExample.java) | `java ListingExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/listing.rb`](ruby/listing.rb) | `ruby listing.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/listing.mjs`](nodejs/listing.mjs) | `node listing.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
